    How results are verified

    This page is a single static file with no server and no stored state — the draft order is computed entirely in your browser from the seed. Anyone can open this same page, enter the same seed, and get the exact same order.

    • The seed is any text; it is trimmed and uppercased, so ab12cd34 = AB12CD34.
    • Team names are sorted alphabetically before shuffling, so the order names were typed in can never influence the result.
    • Randomness comes from the SHA-256 hash of the seed (a public, universal standard), driving an unbiased Fisher–Yates shuffle.
    • The full algorithm is in draft.js — use View Source to audit it.
